# Superior Restoration Demo

Professional restoration company website demo built with Next.js, Tailwind CSS, and Framer Motion.

## Features

- Multi-page restoration service website
- Service section landing pages and detailed service pages
- Booking flow, contact form, chatbot widget, gallery, FAQs, and testimonials
- Responsive layout with branded red and blue styling

## Development

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```
